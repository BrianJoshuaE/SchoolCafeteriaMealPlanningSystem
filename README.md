# School Cafeteria Meal Planning System

This project contains the solution for Question 1 of the OOP Python Programming
Refresher Assignment. It groups students by meal, calculates weekly revenue and
student spending, identifies high spenders, and finds the most popular meal.

## Run

```text
python cafeteria_meal_planning.py
```

When prompted, enter each student's name, meal preference, and daily meal price
in UGX. After each record, enter `y` to add another student or `n` to move to
the weekly calculations and report. You can also enter `done` as the student
name to finish entering records.
